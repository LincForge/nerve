# Contributing

Issues are welcome — bug reports with `nerve doctor` output and the device/OS version help most.

This repository is a **release mirror**: development happens in LINC's private repository and each
release lands here as one commit. Pull requests are accepted **by arrangement** — open an issue
first. If we take your change, we apply it upstream with your authorship credited
(`Co-authored-by`) and it ships in the next release.

All contributions require a Developer Certificate of Origin sign-off: add
`Signed-off-by: Your Name <you@example.com>` to each commit (`git commit -s`).
See https://developercertificate.org/.
